ThreatScope

Detects network intrusions and explains every alert, with a response playbook.

Evaluated on 17 attack types that never appear in its training data.

Try the live demoCode on GitHub

The problem

Intrusion-detection demos often report 99% accuracy by testing on the same attack types they were trained on. Real attackers don't follow those rules.

ThreatScope is evaluated on the NSL-KDD test set, which contains 3,750 connections from 17 attack types absent from training.

How it works

  • Two detectors: a supervised LightGBM model for known attacks, and an autoencoder trained only on normal traffic that flags whatever it cannot reconstruct.
  • Every threshold chosen on validation data, never on the test set.
  • Each alert gets a severity, a SHAP explanation, the features the autoencoder found abnormal, a MITRE ATT&CK technique and a response playbook.

What I learned

Thresholds don't survive distribution shift

Tuned for 1% false alarms on validation data, the supervised model produced 8.1% on the test traffic. The autoencoder's threshold held.

Some attacks are invisible

77 test 'attacks' are byte-for-byte identical to normal connections. No model can catch them from these features, and the project says so.

Limitations

  • NSL-KDD is an old benchmark; modern traffic would need retraining on recent data.
  • Connection-level features only: no payload inspection or correlation across hosts.
